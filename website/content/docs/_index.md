# Documentation

Mergeway keeps a file-based database in a Git repository: entity schemas define the permitted records, and the tools load, validate, modify, compare, and expose that shared data model.

New to Mergeway? Follow [Build your first Mergeway repository](tutorials/first-repository/). It uses one released binary, a fixed example, and checked commands from validation through export. If you need a different platform or installation method, use [Install Mergeway tools](how-to/install/).

Choose a [component](components/) to understand its role in the suite, or browse by the kind of help you need:

- [Tutorials](tutorials/) provide guided learning experiences.
- [How-to guides](how-to/) help you accomplish a specific task.
- [Reference](reference/) records exact interfaces and behavior.
- [Explanation](explanation/) develops concepts and design context.
- [Project](project/) points contributors and release readers to project resources.

## Learn the foundations

- [The Mergeway repository model](explanation/repository-model/) defines repository, workspace, entity, and record.
