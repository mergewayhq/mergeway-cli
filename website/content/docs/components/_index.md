# Components

Mergeway is one suite with several entry points. The specification defines the repository format; the tools validate, operate on, compare, inspect, and edit repositories.

- [Specification](specification/) defines the shared repository and data model.
- [CLI](cli/) operates on and validates repositories.
- [Diff](diff/) compares repository states semantically.
- [Python SDK](python/) automates repositories through a typed Python API.
- [MCP](mcp/) exposes read-only repository inspection to MCP clients.
- [LSP](lsp/) supplies editor diagnostics and navigation.
- [VS Code](vscode/) connects Visual Studio Code to the language server.

Each page states what is available today and where to begin with that interface.
