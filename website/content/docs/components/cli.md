# CLI

`mergeway-cli` is the general-purpose command-line interface for creating and inspecting records, validating and formatting repositories, and exporting repository data. It implements the Mergeway specification and supplies the validation foundation used by other components.

## Availability

The CLI is released for supported platforms in GitHub release archives. It can also be built from this repository; other distribution methods have different component coverage and will be documented precisely in the installation guide.

## Planned documentation

Later phases will add a first-repository tutorial, task-oriented repository guides, and a complete command, flag, output, and exit-code reference.
