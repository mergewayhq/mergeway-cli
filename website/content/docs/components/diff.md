# Diff

`mergeway-diff` compares two repository snapshots and reports semantic record changes. It builds on the same repository model as the CLI so reviewers and automation can reason about added, modified, and removed data rather than only changed lines.

## Availability

Diff is released as a binary in GitHub release archives and can be built from this repository. Its supported snapshot modes and output contracts will be documented from released behavior.

## Planned documentation

Later phases will add guided review workflows, revision-comparison how-to guides, semantic-diff explanation, and complete command and machine-readable output reference.
