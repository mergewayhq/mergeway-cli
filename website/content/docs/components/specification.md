# Specification

The Mergeway specification defines how configuration, entity schemas, records, identifiers, references, and validation fit together in a file-based database. It is the contract shared by the CLI, Diff, MCP, LSP, and editor integrations.

## Availability

Specification version 1 is implemented by the released tools through repositories declaring `mergeway.version: 1`. The reviewed normative reference will be published in a later phase; until then, the existing production documentation and released behavior remain authoritative.

## Planned documentation

Later phases will add the complete normative reference, conformance and terminology rules, checked examples, a changelog, and migration notes. Tutorials and explanations will link to that reference without duplicating it.
