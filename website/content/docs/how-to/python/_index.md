# Python SDK guides

Use these guides to add the `mergeway` package to a Python environment and operate on an existing Mergeway repository.

- [Install the Python SDK](install/) with `uv` or `pip` and verify its CLI dependency.
- [Get started with `mergeway-python`](getting-started/) to generate models and perform common repository operations.
