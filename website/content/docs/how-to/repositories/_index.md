# Repository modeling

These guides apply released Mergeway v0.10.0 behavior to checked example repositories:

- [Reuse a JSON Schema](reuse-json-schema/) for an entity contract maintained outside native `fields`.
- [Load records with JSONPath](load-jsonpath/) from an array inside one JSON document.
- [Model inheritance and reference unions](inheritance-reference-unions/) for polymorphic relationships.
- [Derive identifiers and fields from paths](path-derived-data/) without duplicating location metadata.
- [Load Open Knowledge Format documents](open-knowledge-format/) as records.

Use the [schema design choices](../../explanation/schema-design/) explanation before choosing between these approaches, and consult the [normative specification](../../reference/specification/) for exact constraints.
