# Reference

Reference documentation contains the normative Mergeway specification and exact released tool interfaces. It is intended for lookup and is tied to released behavior.

Start with the [normative specification](specification/) for the version 1 repository contract, use the [`mergeway-cli` reference](cli/) for repository operations, compare revisions with [`mergeway-diff`](diff/), or look up the [`mergeway-mcp` server and tools](mcp/). LSP and VS Code interfaces will be added in their verified phases.
