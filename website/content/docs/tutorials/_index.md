# Tutorials

Tutorials will teach Mergeway through fixed, runnable paths with expected results. The first will build a repository using a tested example; later tutorials will cover semantic review, AI-assisted inspection, and editor workflows.

Detailed tutorials arrive in later phases. For now, use the [component overview](../components/) to choose the part of the suite relevant to you.
